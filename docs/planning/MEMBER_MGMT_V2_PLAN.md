## 2. 목표

1. **안전한 조치**: 삭제·정지가 실패하거나 의도와 다르게 동작하지 않는다(D1·D2·D3).
2. **추적 가능성**: 모든 회원 조치가 누가·언제·왜와 함께 남고 상세에서 바로 보인다(D4).
3. **회원 360°**: 한 화면에서 활동·보안·콘텐츠·내부 메모를 보고 판단한다(D5·D6).

## 3. 기능 정의

### 3-1. 탈퇴 처리 2단계 (D1)
- **탈퇴 처리(소프트)**: `status = DELETED`. 데이터는 보존, 언제든 **복구**(→ ACTIVE) 가능. SA·WM 모두 가능.
- **영구 삭제(하드)**: **WM 전용**, **이미 탈퇴 처리된 회원만** 가능(2단계 안전장치). 삭제 전 연관 데이터를 순서대로 정리한다:
  문의 → 예약(작가/고객) → 포트폴리오(+아이템) → 다른 포트폴리오에 담긴 이 회원 사진·시리즈 아이템 → 피처드·시리즈 연결·댓글(사진 기준) → 사진 → 시리즈 →
  인증 신청 → 신고자 참조는 NULL → 검수자(`portfolios.reviewed_by`) NULL → 댓글·프로필 콘텐츠·뉴스레터·내부 메모(회원 기준) → 회원.
- **App 쪽 후속 과제**: App `AuthService`는 `SUSPENDED`만 로그인 차단하고 `DELETED`는 막지 않는다. App 저장소는 이 세션에서 쓰기 권한이 없어 **수정하지 않았다** — App에 `DELETED` 로그인 차단을 추가해야 탈퇴 처리가 완전해진다.

### 3-2. 정지 만료 자동 해제 (D2)
- 10분마다 `SUSPENDED` 이고 `suspendUntil < now`인 회원을 `ACTIVE`로 되돌리고 `MEMBER_SUSPEND_EXPIRED` 활동 로그(관리자명 "시스템")를 남긴다.
- 상세·목록에 "N일 후 자동 해제"를 표시. 영구 정지(`suspendUntil = null`)는 대상 아님.

### 3-3. 조치 가드 (D3)
- 본인 계정의 역할·상태 변경, 삭제 금지.
- 관리자 계정(WM/SA)의 정지·탈퇴·삭제는 **WM만** 가능.

### 3-4. 관리 이력 · 내부 메모 (D4·D6)
- 역할 변경 / 정지 / 해제 / 탈퇴 / 복구 / 영구 삭제 / 자동 해제를 `admin_activity_logs`(`target_type = MEMBER`)에 기록, 상세 이력에 시간순 타임라인으로 노출.
- **내부 메모**: Admin 전용 신규 테이블 `admin_member_notes`(App과 무관 — 기존 App 테이블은 건드리지 않음). 작성·삭제(작성자 본인 또는 WM). 회원에게는 보이지 않음.

### 3-5. 회원 360° 상세 (D5)
새 탭 3개 추가: **관리**(메모 + 이력) · **댓글**(이 회원이 쓴 App 댓글) · **보안 기록**(로그인 성공/실패·민감 동작, 최근 30일).
프로필 콘텐츠는 `/profile-content?memberId=` 링크로 연결.

### 3-6. 목록 개선 (D6)
- 상단 현황 카드: 전체 · 활성 · 정지(만료 3일 내 n명) · 탈퇴 · 7일 신규 — 카드 클릭 = 상태 필터.
- 상태 필터를 `SegmentedControl`로 통일(탈퇴 상태 포함).
- **CSV 내보내기**: 현재 필터 결과(최대 5,000명), 연락처(tel) 제외, 내보내기 활동 로그 기록.

## 4. API

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/admin/members/summary` | 상태별·신규·만료 임박 |
| POST | `/api/admin/members/export` | body: 목록과 같은 필터 |
| PATCH | `/api/admin/members/{id}/status` | 기존 + 가드·로그. `DELETED`=탈퇴 처리, `ACTIVE`=해제/복구 |
| DELETE | `/api/admin/members/{id}` | WM 전용, `DELETED` 상태만, 연관 데이터 정리 |
| GET | `/api/admin/members/{id}/history` | 활동 로그(target MEMBER) |
| GET/POST | `/api/admin/members/{id}/notes` | 내부 메모 |
| DELETE | `/api/admin/members/{id}/notes/{noteId}` | 작성자 또는 WM |
| GET | `/api/admin/comments?memberId=` | 기존 API에 필터 추가 |
| GET | `/api/admin/security-audit?memberId=` | 기존 API 재사용 |
