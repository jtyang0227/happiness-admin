# 和ドット (와도트) — 일본 분위기 도트 리뉴얼 기획서

Pixel Arcade(네온 아케이드)를 잇는 4차 리뉴얼 제안. "도트"의 DNA는 유지하되,
서구 아케이드 게임기가 아니라 **패미컴 시대 일본 JRPG의 대화창(텍스트 박스) 미학**과
**전통 일본 색채·문양**을 결합한다. 아직 구현 전 — 컨셉 승인 후 토큰·컴포넌트 작업 진행.

## 컨셉 한 줄 요약

"드래곤퀘스트의 남색 대화창 + 목판화의 먹선과 화지(和紙)" — 8비트 도트 질감은 그대로,
색과 장식만 네온 아케이드에서 남색·주색·먹색의 일본 전통 색채로 이동한다.

## 팔레트 — 전통 일본 색채

| 이름 | 한자 | 역할 | Light hex | Dark hex |
|---|---|---|---|---|
| 아이이로 | 藍色 | 배경(다크) / 딥 서피스 | — | `#0F1B2A` |
| 기나리 | 生成り | 배경(라이트, 화지) / 보더(다크) | `#F1E9D8` | `#F1E9D8` |
| 스미 | 墨 | 텍스트 / 보더(라이트, 먹선) | `#1C1B19` | — |
| 슈이로 | 朱色 | 브랜드 · CTA (토리이 문 색) | `#C7361B` | `#E2571C` |
| 와카타케이로 | 若竹色 | 성공 (어린 대나무) | `#3F8A57` | `#6BBF82` |
| 야마부키이로 | 山吹色 | 경고 · 선택 커서 골드 | `#B8791E` | `#F2B84D` |
| 베니 | 紅 | 위험 (홍화 염료) | `#A82530` | `#E0454C` |

라이트 모드는 "먹선이 그려진 화지"(먹색 보더 위에 크림 배경), 다크 모드는 "남색 밤하늘의
대화창"(크림색 보더 위에 남색 배경)으로 — 보더와 배경의 명암이 서로 뒤집히는 것이 이 컨셉의
핵심 아이덴티티다. 기존 Pixel Arcade처럼 보더 색을 라이트/다크 공통으로 쓰지 않는다.

## 모서리 · 프레임

- 모서리는 계속 각짐(`radius: 0`) — 도트 DNA 유지
- 섀도우는 오프셋 드롭섀도우 대신 **2중 픽셀 보더**(JRPG 텍스트박스 특유의 이중 테두리):
  바깥 2px 실선 + 안쪽 1px 여백 + 그림자 없음. 입체감은 그림자가 아니라 보더 두께로 표현
- 주요 패널(카드, 모달) 네 모서리에 작은 ㄴ자 픽셀 브라켓 장식 — 뷰파인더 프레임처럼
- 배경 텍스처: 격자 도트 → **세이가이하(青海波) 물결무늬**를 저채도 픽셀 반복 패턴으로

## 타이포그래피

| 역할 | 폰트 | 용도 |
|---|---|---|
| 포인트 (도트) | `DotGothic16` (Google Fonts) | 브랜드 로고, KPI 숫자, 뱃지 라벨 — 실제 일본 도트 비트맵 폰트 |
| 헤딩 | `Noto Serif KR` (Source Han Serif) | 페이지 타이틀, 섹션 제목 — 명조체, 한글 완전 지원 |
| 본문 | Pretendard (유지) | 표·리스트 등 가독성이 중요한 본문 |

`DotGothic16`은 한글 글리프가 없어 한국어 텍스트는 자동으로 다음 폰트로 폴백된다 — 숫자·영문
라벨에만 적용되므로 문제 없음(Pixel Arcade의 Press Start 2P 적용 방식과 동일).

## 컴포넌트 패턴 (제안)

| 컴포넌트 | 현재 (Pixel Arcade) | 제안 (와도트) |
|---|---|---|
| 카드/패널 보더 | 2px + 하드 오프셋 섀도우 | 2중 픽셀 보더(색 반전), 코너 브라켓 장식 |
| StatusDot | 정사각 픽셀 | 4방향 픽셀 다이아몬드(가문(家紋) 인상) |
| 사이드바 active 표시 | 좌측 3px 바 | 항목 앞에 `▶` 픽셀 커서 — JRPG 메뉴 선택 방식 |
| KPI 프로그레스바 | 세그먼트 블록 | 동일 유지(HP/MP 게이지 인상과 합치) |
| 배경 텍스처 | 도트 그리드 | 세이가이하 물결 픽셀 패턴 |
| 섹션 타이틀 장식 | 없음 | 토리이(鳥居) 실루엣 픽셀 아이콘 마커 |
| 버튼 클릭 피드백 | translate + 섀도우 제거 | 동일 유지 |

## 적용 우선순위 (제안)

Pixel Arcade와 동일하게 토큰(`tokens.css`) + 전역 스타일(`global.css`) 교체만으로 대부분의
화면에 자동 반영 가능. 별도 작업이 필요한 곳은 Sidebar(선택 커서), StatusDot(다이아몬드),
DashboardPage(세이가이하 배경 텍스처) 정도로 예상.

## 결정 필요 사항

1. 이 컨셉으로 실제 구현 진행 여부
2. 라이트/다크 중 하나만 우선 적용할지, 두 테마 동시 적용할지
3. 세이가이하 배경 텍스처를 전 페이지에 적용할지, 대시보드·로그인 등 히어로 영역에만 적용할지
